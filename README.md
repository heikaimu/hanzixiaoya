# 汉字小芽

给小学一年级孩子的亲子识字网页，支持 Supabase 云端保存和离线本机缓存。

## 运行

```sh
npm install
npm run dev
```

需要 Node.js 22.12 或更新版本。打开 http://localhost:5173 。项目使用 Vite，不能直接双击 HTML 运行。测试：`npm test`；构建：`npm run build`。

Supabase 项目配置已写入被 Git 忽略的 `.env`。首次接入需要在 Supabase SQL Editor 中执行 [建表 SQL](supabase/migrations/202610140003_username_passwords.sql)，使用用户名和密码，不需要邮箱验证。详细说明见 [docs/supabase-setup.md](docs/supabase-setup.md)。

## 学习流程

- 不需要先检查全部字库，直接按每日数量从一小组开始，完成后可以继续下一组，当天学习记录会累计。
- “复习汉字”提供独立的到期复习入口，每组按难度最多 10 / 20 / 40 字，可暂停继续；每个过关字立即保存复习结果，不必等待新字或句子完成，也不会重复升级。答错字次日复习。
- “随时练一练”从已学字中按难度随机抽取最多 10 / 20 / 40 字，不要求完成今天的新字，不改变正式复习安排。
- 旧版识字检查记录保留兼容，界面不再提供全字库初始化或批量勾选入口。
- 字库完整对应现行修订版统编人教版一年级语文上下册“识字表”：上册 280 字、下册 410 字，共 690 个会认字，含汉语拼音、识字、阅读和语文园地，按课次及课内字序安排。每字有教材读音、自主整理例词、册别、单元、课名和页码；再次出现的 13 条多音字读音单独展示，不重复计算识字量。教材来源与核对说明见 [docs/textbook-sources.md](docs/textbook-sources.md)。
- 已会字加入复习，未会字按家长设置的每日数量安排；如果今日学习已开始，检查结果从次日生效，不改变正在进行的任务。结果页可查看两类汉字并重新检查，导出备份包含检查进度。
- 家长设置直接切换难度，默认轻松（认字 5、复习 10）；正常（认字 10、复习 20）；困难（认字 20、复习 40）。未开始的当日任务立即更新；已开始任务保留，下一组新字、下一组复习及次日计划使用新设置。到期字按最早到期优先，未安排的字保留到后续日期。
- 按教材课次顺序的内置 690 字字库安排未学过的新字，剩余字数不足每日目标时安排全部剩余字。字库学完后继续复习。
- 家长设置中的“重置识字数”需要再次确认，会清除已认识汉字、识字检查、学习与成长记录，保留每日新字数量，并重新安排今日任务。取消不修改记录。原有“清空学习记录”会同时恢复每日数量为默认值。
- 认读第一轮按教材原始顺序，第二轮起每轮打乱未过关字；每个字独立认对三次才过关。暂停后保留认对次数，第一轮未读完时按剩余字顺序继续。旧版已结算的学习记录保留。认读时拼音始终在汉字上方。“♫ 听一听”仅播放当前字和例词，可反复播放，不跳页、不追加提示，也不自动进入下一字。听过后家长点“读对了”只推进到下一项，本次不计认对，当前字排到队尾再次确认。新字和到期旧字需连续三次未听读音的认对，听读会重置该字本次认对进度。
- 句库包含 163 条人工编写的短句，前 110 个教材汉字可组成其中 90 句。只解锁组成字都已认识的句子；每组安排最多 3 句，优先选择以前没读过的句子，并按日期轮换。首页分别显示可读总数和本组任务数。完成全部字和句子后才标记当日过关。
- 复习间隔为 1、3、7、14、30 天；答错的字重新从 1 天开始。未完成任务刷新后可以继续；逾期未复习的旧字会保留在后续日期的复习计划里。
- 本地日期按浏览器所在时区计算；跨天自动更新。新字未完成过关不会计入永久掌握，第二天继续安排。
- 未登录时保存在浏览器；家长输入用户名和密码注册或登录后自动保存到 Supabase，可在不同设备恢复。支持离线续传、冲突选择、导出、校验导入和清空确认。没有自动语音识别；认读能力依赖家长如实确认，无法保证认知意义上的完全掌握。
- 浏览器朗读使用设备自带中文语音，是否可用取决于浏览器和系统；不可用时由家长示范。

- 汉字库可以按上册、下册筛选，也可以搜索课名。点击汉字可查看课文来源与教材中的其他读音。

## 文件

`index.html` 页面结构，`style.css` 响应式样式，`src/app.js` 交互，`src/main.mjs` SDK 初始化，`src/cloud-progress.mjs` 本机缓存与云端同步，`src/characters.js` 教材字库，`src/sentences.js` 分阶段短句库，`src/learning.js` 学习规则与状态校验。`supabase/migrations/` 存放数据库 SQL，`tests/` 验证学习与保存流程。


## 在线部署

线上地址：https://heikaimu.github.io/hanzixiaoya/

项目通过 `.github/workflows/deploy.yml` 自动部署到 GitHub Pages。仓库 Settings → Pages → Source 选择 **GitHub Actions**，推送到 `master` 后会运行测试、构建和部署。

工作流使用 Supabase 前端 Publishable Key，它是公开客户端配置；数据库访问由密码会话和数据库权限控制。不要填入 `service_role` 或数据库密码。`.env`、浏览器中的账号会话和学习记录不会上传到仓库。

本地开发运行 `npm run dev`，保持根路径；GitHub Actions 构建自动使用 `/hanzixiaoya/` 路径。学习数据保存在已有 Supabase 项目中。
